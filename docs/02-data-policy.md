# 데이터 정책

공개 자료만 사용한다. 주요 사실에 출처를 연결하고 가능한 경우 원문 URL, 발행일, 수집일을 기록한다. 사실과 관찰을 구분하고 데이터가 부족하면 확인 상태를 표시한다.

공개 고객 문의는 개인정보를 제거하고 요약한다. 공지와 문의의 동시 변화는 관찰로 서술한다. 증권사 공시는 비교 가능한 지표만 비교하고 원본 부문 이름을 보존한다. 역사적 시장 데이터는 구성종목 시점과 기업행동 조정 여부를 공개한다.

상세 기준은 [제품 요구사항 18절](Insight_Lab_Requirements_v1.0.md#18-content-and-source-policy)과 [요구사항 감사](Insight_Lab_Requirements_Audit_v1.0.md)를 따른다.
