# 프로젝트 헌장

Insight Lab은 Kiwoom Lab 2기 발표와 개인 포트폴리오를 위한 공개 금융 리서치 사이트다. Astro로 정적 페이지를 만들고 브라우저에서 검색과 탐색을 제공한다. 서비스 데이터는 JSON과 Markdown으로 관리하고 Python 수집·정제 코드는 UI와 분리한다.

Foundation은 공통 탐색 구조와 배포 구성을 마련한다. 이후 Hero Lab, VOC Studio, Broker Atlas, Market Time Capsule, CEO Lens, Normalman Archive 순서로 구현한다.
