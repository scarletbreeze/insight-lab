### 2026년 11월 26일 Market §9.10 · 미국 지수 월간 종가 보완 (Claude Code)

미국 두 지수의 월초·월말 종가 수록 범위를 57개월에서 119개월로 늘려 2016년 12월~2026년 10월을 모두 채웠다. 2021~2023년 24개월은 AP 마감 보도와 공개 전재본 48건을 출처로 하며, 보도값 96개 중 95개가 FRED 관측과 일치했다(2021년 2월 26일 Nasdaq 0.01포인트 차이는 월별 표 아래에 표시). 2016년 12월, 2017~2019년, 2022년 5월의 38개월은 당시 보도를 확보하지 못해 FRED 관측값을 출처로 수록했다. FRED는 두 계열을 재배포 사전 승인이 필요한 자료로 표시하며, 운영자가 2026년 11월 26일 발표용으로 포함을 결정한 사실을 방법론과 해당 월 화면에 공개했다. FRED 출처 월은 호스트로 구분해 교체·제외할 수 있고, 2016~2019년 연말값으로 계산한 연간 수익률은 S&P DJI·Nasdaq 공식 수치와 일치했다. 이후 2008년 1·4~8월 6개월을 AP 마감 보도(스타불러틴 아카이브)로 추가해 125개월이 됐고, Nasdaq 값 12개는 FRED와 일치했다. 2008년 나머지 6개월과 1990년~2016년 11월의 다른 달은 미수록이다.

독립 리뷰어가 신규 보도 출처 16페이지를 다시 조회해 전부 일치함을 확인하고, 119개월 476개 값을 FRED와 대조해 기존 기록 3건 외 차이가 없음과 기존 57개월의 무변경을 확인했다. 검증 스크립트 `scripts/market/verify_us_index_closes.py`와 수집 스크립트 `collect_us_index_closes.py`, Python 테스트 4개를 추가했다.

### 2026년 11월 26일 공통 §20 · Safari(WebKit)·접근성 자동 검사 (Claude Code)

Safari 검증을 위해 Playwright 1.56.1의 WebKit 26.0(빌드 2215)과 Chromium 141, axe-core 4.14.1로 대표 경로 16개를 360·1440px에서 64회, 서비스 하위 메뉴 31개와 동적 경로 표본 18개를 147회 추가 검사했다. 모든 경로에서 콘솔 오류와 가로 넘침은 없었고, WebKit에서 `<select>`가 23px 네이티브 버튼으로 그려지던 문제를 global.css 한 곳에서 통일해 두 엔진 모두 44px로 맞췼다.
