# VOC Studio 공개 자료 조사

## 범위

2022~2026년 공개 고객게시판 원글을 연도와 게시판 분류별로 집계했다. 2022~2025년은 각 달력 연도, 2026년은 11월 25일 기준이다. 공지와 문의 주제의 본문 분석은 원문을 확인한 표본에 근거한다.

## 공지

- [영웅문4 공지 목록](https://www.kiwoom.com/h/hts/popup/VHtsNoticeListPopView?gubun=1&mtsgb=&tp=H4)에서 표시되는 제목, 게시일, 공지 식별자, 원문 URL을 수집한다.
- `python3 scripts/voc/collect_notices.py`는 공개 목록의 현재 표본을 `data/voc/notice-index.json`으로 저장한다. 보관한 목록 HTML이 있으면 `--html`로 재현할 수 있다.
- `data/voc/notices.json`에는 원문을 확인한 공지의 요약이 있다. 공지 식별자로 원문 요약을 우선하여 중복을 제거한다.
- `data/voc/historical-notices.json`은 원문을 확인한 과거 표본 19건이다. 게시일을 가늠할 수 없는 항목은 공지 본문의 적용·안내 대상 날짜를 사용하고 화면에서 표시한다.
- [키우GO 톡](https://www.kiwoom.com/wm/gbi/mm/kiwooGoTalkRndView)의 공개 공지와 [대체거래소 도입 안내서](https://ocrw.kiwoom.com/pdf/guide/Kiwoom_Securities_Alternative_Exchange_Guide_Booklet_Single-Sided.pdf)에서 확인한 5건은 채널을 표시한다.
- 최근 목록에 게시되지 않는 과거 공지의 전체 페이지 범위와 채널별 중복 공지의 식별 방법은 추가 확인이 필요하다.

## 고객문의

- [키움증권 공개 게시판](https://bbn.kiwoom.com/bbs/VBbsBoardBWATZView)에서 비로그인 공개 페이지와 페이지 단위 목록 로딩을 확인했다. 5년을 일관되게 조회할 범위와 연도별 모집단은 확보하지 못했다.
- 저장소에는 표본 질문의 요약, 날짜, 분류, 공개 목록 링크만 저장했다. 작성자 식별자, 고객 계좌 정보, 게시글·답글 원문은 저장하지 않는다.
- 후속 수집에서는 고객 질문, 운영자 답변, 공지, 반복 질문을 구분하고 연도별 수집 개시·종료일과 누락 범위를 기록한다.
- 공지와 문의의 시점 비교에는 공지 게시일 앞뒤 14일간의 같은 주제를 사용한다. 게시 당일은 제외한다. 두 기간을 같은 기준으로 수집했고, 두 기간 합계가 5건 이상이며 차이가 2건 이상일 때 표시한다.
- 연간 집계가 검증된 경우 `data/voc/years.json`에 `questionCoverage: "verified"`, 수집 시작·종료일 `collectionStart`·`collectionEnd`, 수집 기준 `collectionId`를 기록한다. 양 끝이 해당 연도 전체를 포함할 때만 연간 순위를 게시하며 증감 비교에는 같은 수집 기준이 필요하다.

## 사용자 지정 고객게시판

- [키움증권 홈페이지 고객게시판](https://www.kiwoom.com/h/common/bbs/VBbsBoardBWCSZView?dummyVal=0)의 [공개 목록 화면](https://bbn.kiwoom.com/bbs/VBbsBoardBWCSZView) 내 목록 요청을 확인했다. 2026-11-25 첫 페이지 응답은 공지 7건, 고객 원글 7건, 운영자 답글 6건으로 앱의 관찰과 일치했다. 이 응답의 `totalCount`는 0을 반환했으므로 연간 집계에 사용하지 않는다.
- 앱에서 관찰한 고객 글 날짜는 2022-01-01~11-20, 2023-02-06~12-21, 2024-01-19~12-13, 2025-02-27~12-23, 2026-01-10~11-25다. 관찰한 날짜 사이의 모든 페이지 수집이 완료됐다는 의미는 아니다.
- 공개 목록 집계는 공지(`step=0`)와 답글(`pareSeqid>0`)을 제외하고 고객 원글(`step>0`, `pareSeqid=0`, `mngrYn=N`)을 글 번호로 중복 제거한다. 글 번호·날짜·분류 코드만 집계 입력으로 남기고 공개 JSON에는 집계 수치와 검증 범위를 기록한다.
- `python3 -B scripts/voc/collect_public_board.py --first 2022-01-01 --last 2026-11-25 --max-pages 12 --out /tmp/insight-voc-pilot.json`으로 목록 순회와 집계를 재현한다. 12페이지 시험에서는 고객 원글 118건을 확인했다. 게시판이 표시한 분류는 문의 110건, 제안 5건, 칭찬·불만 3건이다. 수집한 페이지에서 본 원글은 11월 19~25일에 걸치며, 가장 오래된 날짜의 모든 게시글을 확인했다는 의미는 아니다. 페이지 제한에 도달했으므로 연간 순위 산정에 반영하지 않는다.
- 90페이지 검증본에서 2026-10-07~11-25에 해당하는 고객 원글 831건을 확인했다. `data/voc/public-board-sample.json`에는 분류별 집계와 확인 범위만 수록한다.
- 20건 단위로 900페이지를 순회해 2026-01-20까지 8,315건을 확인했다. 100건 단위 3페이지와 20건 단위 15페이지의 첫 300행은 식별자와 순서가 일치했다.
- 100건 단위로 1,057페이지를 순회해 2021-12-29까지 확인했다. 2022-01-01~2026-11-25 공개 원글은 48,282건이다. 연도별로 2022년 8,049건, 2023년 9,121건, 2024년 9,729건, 2025년 12,383건, 2026년 9,000건이다. 삭제·비공개 글은 공개 목록의 조회 범위 밖에 있다.
- 재현 명령은 `python3 -B scripts/voc/collect_public_board.py --first 2022-01-01 --last 2026-11-25 --max-pages 1300 --page-size 100 --out /tmp/insight-voc-2022-2026.json`이다. 다시 조회하면 이후 삭제·공개 상태 변경에 따라 결과가 달라질 수 있다.

## 고객문의 주제 자동 집계

- 순회 명령 끝에 `--classify-topics`를 추가하면 게시판에서 문의로 표시한 원글만 분류한다. 제목 일치 용어를 우선 적용하며 제목에서 주제를 찾지 못한 경우 본문 용어를 사용한다. 여러 주제에 일치하거나 주제가 확인되지 않은 경우 상태별로 집계한다.
- 재조회에서 2022~2025년의 전체 및 분류별 건수가 동일했고 2026년 문의 원글이 한 건 늘었다. 첫 주제 집계의 합계는 원글 48,283건, 문의 44,727건이다. 문의 23,269건에 한 개의 주제를 부여했다. 자동 분류는 제목·본문 문맥에 따른 수동 검토와 차이가 있을 수 있다.
- 공개 JSON에는 연도·주제별 건수만 기록한다. 원글과 답글의 텍스트나 작성자 정보는 저장하지 않는다. 이 연도별 집계는 게시물 단위의 대표 질문을 담지 않는다.

## 연도별 대표 문의 예시

- 공개 문의 예시 45건을 연도·주제 화면에 표시한다. 2022년 6건, 2023년 8건, 2024년 8건, 2025년 8건, 2026년 15건이다. 이 중 38건은 공개 제목의 용어에 규칙을 적용해 고른 예시다. 연도와 세부 주제별로 한 건을 남기며 이름, 원문 제목, 본문, 글 번호는 공개 JSON에 넣지 않는다.
- 수집 명령은 `python3 -B scripts/voc/collect_question_examples.py --first 2022-01-01 --last 2026-11-25 --out /tmp/insight-voc-question-examples.json`이다. 예시는 확인 가능한 질문 유형을 보여준다. 주제 빈도는 공개 목록 집계에서 계산한다.

## 일반 공지와 게시일 전후 관찰

- [키움증권 일반 공지](https://bbn.kiwoom.com/bbs/VBbsNoticeNWWNZView)를 15개 단위로 222페이지 순회해 2021-12-22까지 확인했다. 2022년 481건, 2023년 666건, 2024년 699건, 2025년 730건, 2026년 11월 25일까지 738건으로 총 3,314건이다. 이 숫자는 일반 공지 채널에 한정한다.
- 선별 공지의 상세 요청으로 제목·등록일·본문 존재를 대조했다. 같은 국내주식 소수점 매매 안내는 공개 목록에서 확인한 게시일과 원문 주소로 기존 기록을 갱신했다.
- 공개 문의를 날짜와 주제로 집계해 공지 전후 14일씩 비교했다. 원글 총 48,284건과 문의 44,728건을 확인했고, 23,270건이 한 주제로 분류됐다. 기존 분석과 비교해 2026년 공개 문의 한 건이 추가됐다.
- 수집 명령에 `--classify-topics --daily-topics`를 추가하고 로컬 스냅샷을 `scripts/voc/summarize_notice_windows.py`에 입력한다. 공개 JSON은 게시일과 주제가 확인된 34개 공지의 앞뒤 합계만 저장한다. 일별 집계는 로컬 계산에만 사용한다. 같은 로컬 스냅샷을 `scripts/voc/summarize_monthly_topics.py`에 입력해 59개월의 주제별 월 집계를 생성한다. 월별 합산은 기존 연간 분류 건수와 일치해야 한다. 같은 글이 날짜 구간이 겹치는 여러 공지의 관찰에 포함될 수 있다.

## 외부 자료

- 연도별 시장·제도 변화는 `data/voc/context.json`에 기록한다. CEO Lens에 이미 수록한 사건은 같은 원문을 재사용하고 관련 고객 문의 주제에 연결한다.

## 화면번호가 표시된 문의

2026년 11월 26일 재조회에서 2022년 1월 1일~2026년 11월 25일의 문의 44,729건을 확인했다. 이전 주제 집계보다 공개 문의가 한 건 많다. 각 집계는 해당 수집 시점의 분모를 사용한다. 1,057페이지를 순회해 제목 364건에서 Hero Lab에 수록한 화면번호 39종을 확인했다. 하나의 글이 여러 화면을 언급할 수 있다. 화면번호가 대괄호 안에 있거나 ‘화면’과 붙어 있는 제목을 집계하므로 이 수치는 화면 사용 빈도나 모든 관련 문의의 건수를 나타내지 않는다.

재현 명령은 `python3 -B scripts/voc/collect_screen_mentions.py --first 2022-01-01 --last 2026-11-25 --out /tmp/insight-screen-mentions.json`이다.
